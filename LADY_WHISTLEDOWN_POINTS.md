# 🎭 Système Points Lady Whistledown - Guide Rapide

## ✨ Nouvelle Fonctionnalité !

Chaque publication d'article entraîne maintenant **DEUX effets** :

### 📉 Famille perd 10 points
La famille de Lady Whistledown perd 10 points au classement général.

### 📈 Lady Whistledown gagne 10 points  
La personne qui joue Lady Whistledown gagne 10 points personnels !

---

## 🚀 Installation (Si vous avez déjà une base de données)

**Étape 1 : Exécuter la migration**
```bash
migrate-player-points.bat
```

**Étape 2 : Redémarrer le serveur**
```bash
start-server.bat
```

C'est tout ! ✅

---

## 👀 Où voir les points ?

### Page "Mon Espace" (Lady Whistledown uniquement)
Vous verrez :
- ⚠️ Pénalité famille : -10 points
- ✨ Votre gain : +10 points
- 💜 Compteur de vos points personnels

### Page "Classement"
Section Lady Whistledown montre :
- Photo de chaque Lady Whistledown
- Points personnels de chacune
- Qui est la meilleure Lady Whistledown !

## 🎯 Stratégie de Jeu

### Pour la Famille
- Gagner aux mini-jeux = +points
- Publications = -points
- **Objectif** : Maximiser le score total

### Pour Lady Whistledown
- Chaque publication = +10 points personnels
- **Objectif** : Être la Lady Whistledown n°1 !

### Le Dilemme 🤔
Publier aide votre score personnel mais pénalise votre famille...
**À vous de choisir !**

---

## 📊 Exemple Concret

**Famille Bridgerton :**
- Jeux : 100 points

**Daphné (Lady Whistledown) :**
- Publications : 3 articles = +30 points

## ❓ FAQ

**Q : Les points Lady Whistledown comptent dans le score de famille ?**  
R : **NON !** Ce sont deux classements séparés.

**Q : Qui gagne à la fin ?**  
R : Il y a **deux gagnants** :
- La famille avec le meilleur score total
- La Lady Whistledown avec le plus de points personnels

**Q : Puis-je voir les points des autres Lady Whistledown ?**  
R : **OUI !** Sur la page Classement, section Lady Whistledown.

**Q : Que se passe-t-il si un admin supprime un article ?**  
R : Les deux effets sont inversés :
- Famille : +10 points
- Lady Whistledown : -10 points
